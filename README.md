# Summarizer-HF
Text Summarizer App - AI-powered text summarization app using T5 model.

## Tech Stack
-FastAPI(Backend)
-T5 Transformer Model (Hugging Face)
-PyTorch
Jinja2 Templates(Frontend)

## Features
-Text summarization using find-tuned T5 model
-REST API with FastAPI
-Web UI with HTML interface

## How to Run
pip install -r requirements.txt
uvicorn app:app --reload
